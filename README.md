

I am learning DevOps. This project takes one small app (MiniShop: a Flask API with a web page) through the steps a company uses to ship software safely.

**Done so far**
- Git and GitHub: branches, pull requests and version tags
- Tests: automated checks with pytest
- CI: GitHub Actions runs the tests and builds the Docker image on every push
- Docker: the app runs the same way on any machine
- Release v1.0.0

**In progress**
- Release v1.1.0 (search box) and a rollback to v1.0.0

**Goal**
Improve the project step by step: a better UI, more items and features, and turn it into a real shopping site. For that I still need a database, user login, a cart and cloud deployment.
